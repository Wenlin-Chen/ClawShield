# Code of Conduct

## Our Pledge

We want `agent-shield` to be a professional, technically rigorous, and welcoming
project for contributors, users, and researchers. We expect participants to act
with respect, curiosity, and care, especially when discussing security findings,
threat models, and operational failures.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Being respectful in technical disagreement
- Sharing reproducible evidence when reporting bugs or bypasses
- Prioritizing user safety over point-scoring or public takedowns
- Giving actionable review feedback
- Assuming good intent while still being precise about problems

Examples of unacceptable behavior:

- Harassment, threats, discrimination, or personal attacks
- Publicly posting exploitable details for unpatched vulnerabilities
- Sharing secrets, tokens, private keys, or user data in issues or PRs
- Deliberately misleading maintainers or other contributors
- Repeatedly ignoring project contribution or security reporting guidance

## Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing this code of
conduct. Maintainers may remove, edit, or reject comments, commits, code, issues,
and other contributions that violate these standards.

## Scope

This code of conduct applies within project spaces and in public spaces when an
individual is representing the project. This includes issues, pull requests,
discussions, commit messages, release notes, and community chat spaces.

## Enforcement

For conduct concerns, contact the maintainers privately through the repository's
available private contact channel. If the concern is also a security issue,
follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
